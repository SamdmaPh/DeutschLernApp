# Wundervoll — Pitch Presentation

A self-contained investor/partner pitch deck for **Wundervoll** ("German, made wonderful").

## View it
Open `pitch/index.html` in any browser — that's it. No build step, no install.
(Slides are powered by [reveal.js](https://revealjs.com/) loaded from a CDN, so an internet connection is needed the first time.)

### Presenting
- **Arrow keys / Space** — navigate slides
- **F** — fullscreen
- **S** — speaker notes / overview
- **Esc** — slide overview grid

### Export to PDF
Open in Chrome with `?print-pdf` appended to the URL, e.g.:

```
file:///…/pitch/index.html?print-pdf
```

then **Print → Save as PDF** (Layout: Landscape, Margins: None, Background graphics: on).
